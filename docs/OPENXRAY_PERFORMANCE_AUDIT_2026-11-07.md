## Independence

The project keeps its own roadmap and release authority. That includes learning from OpenXRay and taking later patches when they fit. It is not a decision to stop tracking upstream, and it is not a remote, branding, or license change. None was made.

Upstream parity is not required. Current priority is a bounded gain this tree can support: a small diff or a well-owned library, a test or visual contract, and the existing license and attribution left intact. A renderer or physics replacement is a deferred architectural experiment. It needs its own evidence. It is not barred only because it adds a third-party library. Content stays CoC 1.4.12 plus 1.4.22 with the explicit target overlay. Do not take a patch that changes save layout, Lua exception behavior, or the Darwin no-exceptions / bridge / xrSim rules. None of the candidates below is implemented here. Standalone frame-time checkpoint `e3f273f04bf85b4b265004cbbc8a35f19796cd31` is reviewed, and engine hooks are in progress. A same-binary clock only attributes intervals inside one binary. It does not close the overhead gate in [the frame-time measurement plan](superpowers/plans/2026-11-07-frame-time-measurement.md). That gate stays open until a common external or separately gated reference can measure disabled and pre-change binaries. Do not substitute bridge FPS or donor autotest totals.

## What this audit does not claim

IXRay / donor `calc_ms`, `dump_ms`, `total_ms`, and hidden autotest time are not comparable full-loop measurements. Nothing here says the NVRHI or Vulkan renderer is faster than the current OpenGL path. Nothing here authorizes a remote rename, a license rewrite, or a dependency bump. Selective upstream intake remains possible after a gate. The physics decision is the linked report above: no ready-to-port measured speedup, so those stacks stay deferred. A same-binary clock attributes time inside one binary and leaves the overhead gate open. A future query-equivalence check must accept a legitimate equal-distance triangle tie when geometry and material match. A different triangle id alone is not a failure. No local benchmark was run, and physics provenance stays in `artifacts/openxray-physics-audit/provenance.md`.
